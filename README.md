# Generative AI Developer

I build practical Python applications that use language models to answer questions from relevant source material.

## Featured Project

### [DocuMind: PDF RAG Chatbot](https://github.com/racerrajesh1413-art/Rag-chatbot)

A Streamlit app that answers questions using an uploaded PDF. It extracts and chunks document text, creates local embeddings, retrieves relevant passages with FAISS, and sends the context to Google Gemini for an answer.
